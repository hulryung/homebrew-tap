# homebrew-tap

Personal Homebrew tap for macOS applications.

## Usage

```bash
brew tap hulryung/tap
```

## Available Casks

| Cask | Description | Version |
|------|-------------|---------|
| `claude-rate-widget` | macOS widget that monitors Claude Code rate limits | 1.4.1 |
| `hangulkeychanger` | Remap keys for Korean/English input switching on macOS | 2.3.0 |
| `mac-mouse-scroll-is-bulpyun` | Reverse mouse scroll direction without affecting trackpad | 1.0.0 |
| `markdown-prism` | Native macOS Markdown viewer and editor with live preview | 0.2.0 |

### Install

```bash
brew install --cask hulryung/tap/<cask-name>
```

For example:

```bash
brew install --cask hulryung/tap/hangulkeychanger
brew install --cask hulryung/tap/claude-rate-widget
brew install --cask hulryung/tap/mac-mouse-scroll-is-bulpyun
brew install --cask hulryung/tap/markdown-prism
```
